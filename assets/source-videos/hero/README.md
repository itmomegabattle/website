# Hero video source files

These files are source/original hero videos kept for future re-encoding.

They are intentionally stored outside `public/`, so Vercel does not serve them as website assets.

Production files used by the website:

- `public/hero-video.mp4` — optimized desktop hero video.
- `public/hero-video-mobile.mp4` — optimized mobile hero video.

Original source files:

- `hero-video-desktop-original.mp4`
- `hero-video-mobile-original.mp4`

If the hero needs to be reworked, use these source files and export optimized versions back into `public/`.
